## 2. 背景

### 2.1 当前问题

桌面端当前仅显示一个状态文本，无法表达目标进程选择、活动诊断会话、实时内存时间线、快照集合和快照分析结果。

### 2.2 问题影响

用户无法在一个界面内判断当前诊断证据是否可用，也无法从类型统计继续钻取到对象、引用路径或快照对比。

### 2.3 建设原因

现有 Application 与 Orchestration 契约已经定义了实时会话、快照导入、快照分析和对比能力，需要先用可交互原型验证工作台的信息层级。

## 3. 目标

### 3.1 主要目标

- 用户可以从同一启动页选择实时附着或打开 `.gcdump`。
- 用户可以在同一工作台查看会话时间线、快照集合和快照分析入口。
- 用户可以通过交互演示类型、对象、引用路径、保留路径和快照对比的层级关系。
- 用户可以识别完整、部分、不可用和失败四种证据质量。

### 3.2 非目标

- 不连接真实 Diagnostics 服务，不枚举本机进程。
- 不执行真实快照捕获、文件解析或对象查询。
- 不替代 WPF 生产界面的组合根、ViewModel 或 Application 契约。

## 4. 范围

### 4.1 包含范围

| 模块 | 功能 | 是否包含 |
|---|---|---|
| 启动页 | 实时附着入口、快照导入入口、最近记录 | ✅ |
| 实时会话 | 目标摘要、能力状态、内存时间线、捕获操作 | ✅ |
| 快照分析 | 概览、类型、对象、引用/保留路径、支配树入口 | ✅ |
| 快照对比 | 基线/候选选择和类型变化表 | ✅ |
| 状态演示 | 加载、分析中、质量和失败提示 | ✅ |

### 4.2 不包含范围

| 模块 | 功能 | 原因 |
|---|---|---|
| Diagnostics | 真实进程附着和快照解析 | 原型只验证界面结构 |
| 持久化 | 保存用户设置和分析历史 | 不属于本轮交互验证 |

## 5. 术语与定义

| 术语 | 定义 |
|---|---|
| 实时会话 | 已附着目标进程并持续提供内存时间线的分析上下文 |
| 快照 | 已保存或已导入、可以重新分析的内存快照 |
| 基线/候选 | 用于快照比较的前后两个快照 |
| 证据质量 | 对结果完整性和缺失信息的可见分类 |
| Retention | 以保留路径和根证据解释对象为何仍存活的分析方式 |

## 6. 功能规格

## 6.1 双入口启动

### 功能描述

启动页必须让用户选择实时诊断或快照分析，并保持两种入口在同一产品上下文内。

### 输入

- 用户点击“附着运行中的进程”“启动并附着目标程序”或“打开 `.gcdump`”。

### 处理逻辑

1. 展示两种入口及最近分析记录。
2. 用户选择实时入口时，进入实时会话工作区；选择快照入口时，进入快照分析工作区。
3. 原型使用带来源标记的模拟目标或快照数据。

### 输出

- 当前工作区切换为实时会话或快照分析。

### 异常情况

| 异常 | 系统行为 |
|---|---|
| 未选择入口 | 保持启动页，不创建分析上下文 |
| 快照不可用 | 展示失败提示和重新选择操作 |

## 6.2 实时会话工作区

### 功能描述

展示目标身份、能力状态、托管堆/进程内存时间线和快照捕获操作。

### 输入

- 模拟目标进程、能力摘要、内存样本和快照列表。

### 处理逻辑

1. 顶部显示进程名、PID、运行时、架构和会话状态。
2. 中央区域显示托管堆与进程内存两条时间线，并标记时间范围。
3. 右侧显示标准快照、Retention 快照和执行采样能力。
4. 用户点击捕获操作时，显示采集中、分析中和完成状态。

### 输出

- 可识别的活动会话、时间线、能力和最近快照。

### 异常情况

| 异常 | 系统行为 |
|---|---|
| 目标退出 | 会话状态显示“已结束”，保留已保存快照 |
| 能力不可用 | 禁用对应操作并展示稳定原因 |
| 时间线存在缺口 | 显示“部分证据”，不把缺失点绘制为零 |

## 6.3 快照分析工作区

### 功能描述

展示快照概览并支持从类型统计进入对象、引用路径和保留路径。

### 输入

- 当前快照、类型统计、对象摘要、路径摘要和质量信息。

### 处理逻辑

1. 显示快照来源、捕获时间、对象数和分析质量。
2. 类型表按浅表大小展示对象数、浅表大小和保留大小。
3. 点击类型行后打开对象分页视图。
4. 点击对象后在右侧展示地址、大小、类型和引用/保留路径。
5. 对象数达到大快照阈值时，界面显示分页提示。

### 输出

- 类型列表、对象列表和路径详情。

### 异常情况

| 异常 | 系统行为 |
|---|---|
| 基础索引不可用 | 展示分析失败和重试操作 |
| 派生路径不可用 | 保留类型/对象结果，单独标记路径不可用 |
| 对象数量过大 | 只展示分页入口，不显示完整枚举承诺 |

## 6.4 快照对比

### 功能描述

允许用户选择基线和候选快照，查看类型数量与浅表大小变化。

### 输入

- 快照集合中的两个不同快照。

### 处理逻辑

1. 用户分别选择基线和候选快照。
2. 系统展示两份快照的来源、时间和质量。
3. 系统按类型身份展示对象数和浅表大小增减。

### 输出

- 增长、减少和未变化的类型比较表。

### 异常情况

| 异常 | 系统行为 |
|---|---|
| 未选择完整的基线/候选 | 显示选择提示，不执行比较 |
| 比较能力不可用 | 显示稳定原因，保留快照分析页面 |

## 7. 数据规格

### 7.1 数据结构

原型内部使用以下模拟数据字段：

```json
{
  "workspace": "live | snapshot | compare",
  "target": { "name": "", "pid": 0, "runtime": "", "architecture": "" },
  "quality": "complete | partial | unavailable | failed",
  "snapshots": [{ "id": "", "origin": "live | imported", "status": "ready" }]
}
```

### 7.2 字段定义

| 字段 | 类型 | 单位 | 必填 | 默认值 | 范围/说明 |
|---|---|---|---|---|---|
| workspace | string | - | 是 | live | live、snapshot、compare |
| pid | integer | - | 否 | null | 仅实时目标使用 |
| quality | string | - | 是 | complete | complete、partial、unavailable、failed |
| snapshot.id | string | - | 是 | - | 当前原型内唯一标识 |
| snapshot.origin | string | - | 是 | - | live 或 imported |

### 7.3 枚举定义

| 值 | 名称 | 说明 |
|---|---|---|
| live | 实时会话 | 来自活动附着会话 |
| snapshot | 快照分析 | 来自已保存或导入快照 |
| compare | 快照对比 | 来自基线和候选快照 |
| complete | 完整 | 证据完整且可验证 |
| partial | 部分 | 存在明确缺失但结果可用 |
| unavailable | 不可用 | 当前能力不足 |
| failed | 失败 | 处理失败，不能视为成功证据 |

## 9. 业务流程

### 9.1 正常流程

```text
启动页
 ↓
选择实时附着或打开快照
 ↓
进入统一诊断工作台
 ↓
查看时间线或快照概览
 ↓
钻取类型 → 对象 → 路径
 ↓
选择基线/候选并查看比较
```

### 9.2 异常流程

```text
选择能力不可用的操作
 ↓
显示稳定原因
 ↓
保留其他可用分析区域
```

## 10. 状态机

```text
启动页 → 实时会话 → 快照分析 → 快照对比
   └──────────────→ 快照分析
```

### 状态定义

| 状态 | 进入条件 | 退出条件 | 系统行为 |
|---|---|---|---|
| 启动页 | 文档首次打开 | 选择入口 | 展示双入口和最近记录 |
| 实时会话 | 选择附着入口 | 切换导航或结束会话 | 展示目标、时间线和捕获操作 |
| 快照分析 | 选择快照入口或快照导航 | 切换导航 | 展示快照分析层级 |
| 快照对比 | 选择对比导航 | 切换导航 | 展示基线/候选和变化表 |
| 失败/不可用 | 操作返回失败或能力缺失 | 重试或离开当前区域 | 显示原因，不覆盖其他结果 |

## 11. 异常处理

| 场景 | 检测条件 | 系统行为 | 日志级别 |
|---|---|---|---|
| 未选择入口 | 用户未完成入口选择 | 保持启动页 | 不适用 |
| 能力不可用 | 能力标记为 unavailable | 禁用对应按钮并显示原因 | 不适用 |
| 目标结束 | 会话状态为 Ended | 显示已结束并保留已保存快照 | 不适用 |
| 分析失败 | 快照状态为 failed | 显示失败原因和重试按钮 | 不适用 |

### 异常处理原则

1. 原型状态不得导致页面崩溃。
2. 不可用能力不得伪装成成功结果。
3. 失败区域不得覆盖仍然可用的分析结果。
4. 时间线缺失不得绘制为零值。
5. 所有失败状态必须提供可识别的原因。

## 18. UI 规格

- 启动页必须同时展示实时入口和快照入口，入口以桌面命令区和工作区内容呈现，不使用营销式首屏。
- 工作台必须采用 Windows 桌面工具结构：窗口标题栏、命令栏、左侧工作区树、顶部上下文栏、标签页和中央分析区；对象详情可以从右侧抽屉打开。
- 视觉基座使用 Fluent/Visual Studio 风格的中性灰表面、单一 Windows 蓝强调色、4px 控件圆角和 1px 分隔线；不使用渐变、霓虹、深色品牌侧栏或大面积悬浮阴影。
- 工作区必须同时提供浅色和深色主题切换，主题切换不得改变信息层级和状态语义。
- 加载、分析中、部分证据、不可用、失败和已结束状态必须有稳定的文字标签与颜色区分。
- 类型和对象表必须支持筛选及行点击钻取；大快照必须显示分页语义。
- 基线与候选快照必须可以分别选择。
- 空状态必须提供下一步操作，不显示空白面板。

## 19. 验收标准

### 19.1 功能验收

### AC-001 双入口

**条件：** 页面首次打开。

**操作：** 分别点击实时入口和快照入口。

**预期：** 两次操作分别进入实时会话和快照分析工作区。

### AC-002 实时工作区

**条件：** 已进入实时会话。

**操作：** 查看顶部目标摘要和中央时间线。

**预期：** 页面显示进程名、PID、运行时、托管堆和进程内存两条曲线。

### AC-003 快照钻取

**条件：** 已进入快照分析。

**操作：** 点击类型行，再点击对象行。

**预期：** 类型表切换为对象列表，右侧展示对象信息和路径入口。

### AC-004 快照对比

**条件：** 已存在两份快照。

**操作：** 选择基线和候选快照。

**预期：** 对比区域显示类型数量和浅表大小变化。

### AC-005 质量状态

**条件：** 时间线或能力数据标记为 partial/unavailable/failed。

**操作：** 查看对应区域。

**预期：** 区域显示明确质量标签和原因，不把缺失数据显示为零。

### AC-006 桌面端主题与工作区结构

**条件：** 页面首次打开。

**操作：** 查看窗口框架、命令栏、左侧工作区树和中央标签页，然后切换一次主题。

**预期：**

1. 页面显示桌面工具结构，不显示营销页式首屏或深色品牌侧栏。
2. 切换后浅色和深色主题均保留相同的导航、表格和状态语义。
